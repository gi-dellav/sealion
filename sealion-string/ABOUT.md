# About sealion-string

`sealion-string` is Sealion's Latin1/UTF-16 encoded, reference counted,
immutable ECMAScript string implementation.

It is derived from the [`boa_string`](https://github.com/boa-dev/boa/tree/main/core/string)
crate from the [Boa](https://boajs.dev/) project, which is licensed under
`Unlicense OR MIT`. See `LICENSE-MIT` and `LICENSE-UNLICENSE` for the upstream
license texts.
